================================================================================
AI README: Archived Changelogs and Debugging Reports Folder
================================================================================

PURPOSE:
--------
This folder stores completed changelogs and resolved debugging reports that
are kept for historical reference.

WHEN TO ARCHIVE DOCUMENTS HERE:
--------------------------------
Move documents to this folder when:

1. Changelog entries are for released versions
2. Debugging reports are for resolved issues
3. Issue analysis documents are for closed issues
4. Historical debugging sessions are no longer relevant
5. Reports document issues that are completely resolved

WHAT GOES HERE:
---------------
- Changelog entries for past releases
- Completed debugging reports
- Resolved issue documentation
- Historical bug analysis
- Closed issue reports

NAMING CONVENTION:
------------------
Use descriptive names with date prefixes:

- Changelogs: CHANGELOG_v1.0.0.md or CHANGELOG_YYYY-MM-DD.md
- Debugging: DEBUG_YYYY-MM-DD_IssueName.md
- Issues: ISSUE_#123_Description.md or ISSUE_YYYY-MM-DD_Description.md
- Examples:
  - CHANGELOG_v1.0.0.md
  - DEBUG_2024-02-12_Note_Save_Failure.md
  - ISSUE_2024-02-12_GUI_Layout_Issue.md

ARCHIVE WORKFLOW:
-----------------
1. Verify issue/changelog is complete and resolved
2. Ensure all related documentation is included
3. Move document to this folder
4. Update any references in active documents
5. Commit with descriptive message

RELATIONSHIP TO DEVELOPMENT JOURNEY:
------------------------------------
Note: Development journey documents (00_Dev_Journey_*.md) are stored in
00_Development_Journey_Lessons_Learned/ folder, not here. This folder is for:
- Changelogs (version release notes)
- Debugging reports (specific debugging sessions)
- Issue reports (bug tracking documents)
