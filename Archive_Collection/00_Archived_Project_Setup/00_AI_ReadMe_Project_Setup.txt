================================================================================
AI README: Archived Project Setup Folder
================================================================================

PURPOSE:
--------
This folder stores documents created during the initial project
conceptualization and planning phase - documents that were created before the
project was "crystallized" (before active development began).

This folder is specifically for "pre-crystallized decisions aid docs" - planning
and research documents that helped shape the project but are no longer needed
for active development.

WHAT GOES HERE:
---------------
- All "01_*" documents (eventually, as they become less relevant to active
  development)
- Other pre-crystallized decision aid documents from the initial planning phase
- Research documents that informed initial decisions but are no longer actively
  referenced
- Planning documents from the conceptualization phase

EXCLUSIONS:
----------
- "00_*" documents are NOT included in this folder
- "00_*" documents are permanent, maintained documents that should remain in
  the top-level directory
- Examples of permanent "00_*" docs:
  * 00_AI_ReadME_Project_Guidance_And_Rules.md
  * 00_Codebase_Comments_Guidelines.md
  * 00_Project_Desires.md
  * 00_Development_Journey.md
  * etc.

WHEN TO ARCHIVE DOCUMENTS HERE:
--------------------------------
Move documents to this folder when:

1. Project has moved from planning/conceptualization to active development
2. Documents are "pre-crystallized" - they helped make decisions but those
   decisions are now finalized
3. Documents are no longer actively referenced during development
4. Research/planning phase is complete and implementation has begun
5. Documents served their purpose in shaping initial project direction

TIMING:
-------
Documents can be moved here:
- After project setup is complete
- When transitioning from planning to development phase
- When decisions documented in these files are finalized and implemented
- When documents are no longer needed for day-to-day development

NAMING CONVENTION:
------------------
- Keep original filename when moving documents
- Documents maintain their original "01_*" prefix
- No need to add date prefixes (these are historical planning documents)

ARCHIVE WORKFLOW:
-----------------
1. Verify document is from pre-crystallization/planning phase
2. Confirm document is no longer needed for active development
3. Ensure decisions documented are finalized
4. Move document to this folder
5. Update main AI ReadME if document was listed there
6. Commit with descriptive message

RELATIONSHIP TO OTHER ARCHIVE FOLDERS:
---------------------------------------
This folder is specifically for:
- Initial project planning/conceptualization documents
- Pre-crystallized decision aid documents

Other archive folders serve different purposes:
- 00_Archived_Research/ - Research documents (can overlap, but this folder
  is specifically for initial project setup phase)
- 01_Archived_Implementation_Plans/ - Implementation plans (post-crystallization)
- 02_Archived_Test_Scripts/ - Test files
- 03_Archived_Changelogs_And_Debugging_Reports/ - Changelogs and debugging

REFERENCE:
----------
See 00_AI_ReadME_Project_Guidance_And_Rules.md Section 4.4 for general
archive folder guidelines.
